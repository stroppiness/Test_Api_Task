# Тестовое задание

## Краткое описание:
API-сервис для создания кошелька, изменения, а также представления баланса.

## Авторы проекта:

### Стукалов Сергей

## Стек технологий:
1. python
2. FastAPI
3. SQLAlchemy
4. Alembic
5. PostgreSQL

## Установка и запуск через docker-compose:
1. При необходимости можете проверить корректность ответов от ручек при помощи python -m pytest из корневой директории.
2. Создайте .env с параметрами, приведёнными ниже, а также в .env.example
3. Запустите docker-compose.yml при помощи docker compose up, находясь в корневой директории.

## Переменные окружения:
| Переменная | Описание | Пример значения |
| :--- | :--- | :--- |
| **`DB_HOST`** | Токен Telegram-бота | `localhost или имя контейнера` |
| **`POSTGRES_USER`** | Имя пользователя в БД | `postgres` |
| **`POSTGRES_PASSWORD`** | Пароль для базы RabbitMQ | `my_password` |
| **`POSTGRES_DB`** | URL для обращений к RabbitMQ | `db` |
